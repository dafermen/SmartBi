# Checklist de aceptación final — SmartBI v0.1.0

## Escala

- `[x]` Aprobado.
- `[ ]` No probado.
- `[!]` Encontró un problema.

## A. Carga y cambio de archivo

- [ ] Entiende qué tipo de archivo debe cargar.
- [ ] Puede seleccionar o arrastrar un `.xlsx` válido.
- [ ] Comprende los mensajes de error y advertencia.
- [ ] Puede cancelar “Cambiar archivo” sin perder el dashboard anterior.
- [ ] La flecha atrás funciona como se espera durante el cambio de archivo.

Observaciones:

## B. Wizard

- [ ] El wizard comienza en el paso 1.
- [ ] Entiende la agrupación principal.
- [ ] Puede elegir varias agrupaciones secundarias.
- [ ] Entiende la diferencia entre descripción y métrica.
- [ ] Puede elegir columnas incluidas y filtros.
- [ ] “Seleccionar todo” y “Deseleccionar” funcionan.
- [ ] La vista previa ayuda a tomar decisiones.
- [ ] Puede volver atrás sin perder lo elegido.

Observaciones:

## C. Dashboard y filtros

- [ ] Los KPIs son comprensibles.
- [ ] La búsqueda global filtra el reporte.
- [ ] Los filtros laterales y segmentadores funcionan.
- [ ] Los rangos numéricos y de fecha funcionan cuando aplican.
- [ ] Puede quitar filtros mediante chips.
- [ ] Los gráficos, KPIs y tabla permanecen sincronizados.
- [ ] Puede exportar CSV.

Observaciones:

## D. Páginas y visuales

- [ ] Puede crear, duplicar, renombrar, ocultar y restaurar páginas.
- [ ] Puede reordenar páginas.
- [ ] Puede elegir la página inicial.
- [ ] Entiende que cada página puede tener visuales propios.
- [ ] Puede crear un visual y escoger tipo, agregación, color y tamaño.
- [ ] Puede editar, duplicar, ordenar, quitar y eliminar un visual.
- [ ] La composición se conserva al recargar el navegador.

Observaciones:

## E. Tabla y rendimiento

- [ ] Puede buscar, ordenar y cambiar filas por página.
- [ ] Los lotes de 100 o 250 filas se desplazan con fluidez razonable.
- [ ] Un archivo grande muestra avisos comprensibles.
- [ ] El perfil de columnas no congela la interfaz de forma prolongada.

Observaciones:

## F. Accesibilidad

- [ ] Completa el flujo principal usando solo teclado.
- [ ] El foco siempre es visible.
- [ ] Las pestañas responden a flechas, Inicio y Fin.
- [ ] Al 200 % de zoom, el contenido sigue siendo utilizable.
- [ ] El tema claro tiene contraste suficiente.
- [ ] El tema oscuro tiene contraste suficiente.
- [ ] NVDA o VoiceOver anuncia controles, estados y tablas de forma comprensible.
- [ ] No existen controles que dependan únicamente de arrastrar.
- [ ] El contenido sigue siendo entendible sin depender únicamente del color.

Observaciones:

## G. Documentación y aprendizaje

- [ ] Puede abrir la documentación desde la aplicación.
- [ ] Encuentra el manual de usuario.
- [ ] Los ejemplos y analogías son comprensibles.
- [ ] La búsqueda y navegación entre capítulos funcionan.
- [ ] No aparecen caracteres dañados.
